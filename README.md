# Book Tracker - Трекер прочитанных книг

**Автор:** [Макухин Никита]

##Описание программы

Book Tracker - это приложение для ведения списка прочитанных книг. Программа позволяет:
- Добавлять книги с указанием названия, автора, жанра и количества страниц
- Фильтровать книги по жанру и количеству страниц
- Искать книги по названию или автору
- Сохранять и загружать данные в формате JSON
- Просматривать статистику прочитанных книг

## Требования для запуска

- Python 3.8 или выше
- Стандартные библиотеки (tkinter, json, datetime, os, unittest)

## Инструкция по запуску

### Способ 1: Запуск из VS Code
1. Откройте папку `book_tracker` в VS Code
2. Откройте файл `main.py`
3. Нажмите кнопку Run в правом верхнем углу

### Способ 2: Запуск из командной строки

# Запустите программу
